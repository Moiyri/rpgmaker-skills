# 引擎固定编号

这些编号由引擎定义，不属于 System Types 可编辑字段。

## parameters（基础能力）

0 最大HP / Max HP｜1 最大MP / Max MP｜2 攻击力 / Attack｜3 防御力 / Defense｜4 魔法攻击 / Magic Attack｜5 魔法防御 / Magic Defense｜6 敏捷 / Agility｜7 幸运 / Luck

## extra_parameters（追加能力）

0 命中率｜1 闪避率｜2 暴击率｜3 暴击闪避率｜4 魔法闪避率｜5 魔法反射率｜6 反击率｜7 HP再生率｜8 MP再生率｜9 TP再生率

## special_parameters（特殊能力）

0 被攻击率｜1 防御效果率｜2 恢复效果率｜3 药理知识｜4 MP消耗率｜5 TP充能率｜6 物理伤害率｜7 魔法伤害率｜8 地形伤害率｜9 经验获得率

## slot_types（装备槽类型）

0 普通｜1 双持

## special_flags（特殊标记）

0 自动战斗｜1 防御｜2 掩护｜3 保留TP

## collapse_types（消失效果）

0 普通｜1 Boss｜2 瞬间消失

## party_abilities（队伍能力）

0 遇敌减半｜1 无遇敌｜2 取消偷袭｜3 先制率提升｜4 金币双倍｜5 掉落物品双倍
