# Lighting Requires Visual Review

## 所需插件

地图光照候选为 `Community_Lighting_MZ.js`，详见[插件资料](../references/plugins/community-lighting.md)。

## 用户经验

Community Lighting 由 agent 编辑出来的效果可能不好。这是制作效果的提醒，不是禁止 agent 配置，也不代表插件本身不好用。

## 应用方式

先查看地图和用户期望的氛围、参考效果，优先沿用工程中已有且用户认可的布光。需要新调整时，先在已授权地图的局部范围配置，再查看游戏实际画面，根据反馈调整半径、颜色、环境亮度和遮挡；不要凭参数值推断美术效果已完成。

检查角色与道路是否可辨、明暗是否符合场景、光源与地图物件位置是否吻合，以及移动/转场后的表现。agent 可以提供可运行的初稿，最终观感交用户确认；无法查看游戏画面时明确只完成配置，提供用户检查方法。不因此自行创建未授权的测试地图或事件。

经验来源：2026-10-12 用户提醒。上面的检查方法用于落实该提醒，未记录为用户已验证的固定光照参数。
