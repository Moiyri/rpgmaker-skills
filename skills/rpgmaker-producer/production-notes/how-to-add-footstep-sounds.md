# How to Add Footstep Sounds

## 使用插件

`GabeMZ_StepSound.js`，用于角色行走脚步声。[作者仓库](https://github.com/comuns-rpgmaker/GabeMZ)，[插件参考](../references/plugins/gabe-step-sound.md)。

## 默认制作方式

一般使用地图区域 ID 标记脚步材质，按用户习惯从 **131** 开始分配，后续材质继续分配可用区域 ID。区域分配统一见[项目架构](../references/project-architecture.md#区域-id)。先检查现有占用，尤其是通行规则、触发区域及其他插件的区域用途，再确定材质与区域 ID 对应关系。

先配置插件中的脚步音效组，再在地图绘制区域标记，在地图备注写对应关系。例如 `<stepSound 131: 1>` 表示区域 131 使用音效组 1；音效组与材质的具体映射按实际配置确定，不猜测。

如果用户已经准备了供无限图层使用的图层素材，另行讨论脚步标记与制作方法，先核对相关图层插件和素材。不预设 Gabe 插件能直接从图层图片读取脚步材质，也不自动设计额外检测方案。

## 实施与测试

先阅读插件帮助，通过正式插件脚本修改参数，通过数据库／事件技能修改地图数据和备注。测试不同材质区域的切换、行走与冲刺的播放节奏；需要时检查跟随者及事件脚步声是否符合预期。

来源：用户于 2026-10-12 指定插件、区域 ID 默认方式和从 131 开始的习惯。配置语法已核对本地 1.1.1 帮助，未修改工程，未做运行测试。
