# 制作手记

记录用户在实际制作中的经验、习惯、问题处理与插件搭配，独立于备选插件库。按主题逐篇积累；处理相关需求时只读取对应手记，不一次加载全部内容。

每篇说明适用场景、现象、处理方法、必要的参数或操作位置，以及经验来源和验证程度。用户经验、源码核对和运行验证分别记录；不把某个项目的有效做法扩展成所有项目的强制设置。后续修正直接更新对应主题。
