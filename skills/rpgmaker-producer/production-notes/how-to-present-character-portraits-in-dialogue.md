# How to Present Character Portraits in Dialogue

## 所需插件

使用 **`LL_StandingPicture.js`**（Lulu’s Church），[官方说明](https://nine-yusha.com/plugin-spicture/)。本次核对 shadow 本地 MZ 版 2.6.3，完整注册名为 `ui/LL_StandingPicture`。使用前确认已注册、启用，具体资料见[插件条目](../references/plugins/ll-standing-picture.md)。

## 站位与素材

用户偏好：只有一个主要角色时放在左边；出现第二个角色时放在右边，并设置水平反转。

将立绘槽 1（\F）配置在左侧，槽 2（\FF）配置在右侧。槽号本身不代表左右，必须根据工程分辨率和实际素材设置坐标，不能照搬插件默认位置。角色站位与出场顺序分开：即使右侧角色先说话，也仍从右侧出场。

在 `sPictures` 中配置立绘 ID 与图片。`x/y` 对应槽 1，`x2/y2` 对应槽 2；右侧角色的 `reverse` 设为 `-1`（Flip horizontal），该设置作用于槽 2、4。不要再用负缩放重复反转。

素材放 `img/pictures/`。先检查用户文件，根据画面布局告知所需尺寸、透明背景、对齐与命名，由用户处理好后交给 agent 写入工程。具体坐标、缩放和暗化程度按工程确定，不从这条经验推导固定数值。

## 出场与发言

先说话的人先出现，不在对话开始时把所有人一次摆出来。另一人轮到发言时再显示；已经出场的人可保留在画面上。

每句对白都明确设置说话者聚焦：

| 情况 | 控制符 | 效果 |
| --- | --- | --- |
| 左侧角色出现 | `\F[角色立绘ID]` | 显示槽 1 |
| 右侧角色出现 | `\FF[角色立绘ID]` | 显示槽 2，使用已配置的反转 |
| 左侧发言 | `\AA[F]` | 聚焦左侧，其他已显示角色变暗 |
| 右侧发言 | `\AA[FF]` | 聚焦右侧，其他已显示角色变暗 |
| 旁白 | `\AA[N]` | 所有已显示立绘变暗（darken all） |

`\AA` 指定立绘槽，不是角色 ID。不说话的人通过聚焦规则自动 darken，无需逐个调整色调。旁白不要使用 `\AA[R]`，它是重置聚焦，不是全暗。

如果角色需要跨对白保留，可在这段对话开始时用 `\FH[ON]` 开启保持；段落结束时用 `\FH[OFF]` 取消保持，并检查窗口关闭后的退场。保持模式与退场应按实际演出使用，不擅自增加其他动作或动画。

## 两人对话示例

以下假设左侧角色先发言，`left_id` 和 `right_id` 替换为已配置的立绘 ID：

```text
第一句：\FH[ON]\F[left_id]\AA[F]左侧角色的台词。
第二句：\FF[right_id]\AA[FF]右侧角色的台词。
第三句：\AA[F]左侧角色再次发言。
旁白：\AA[N]旁白内容。
```

若右侧先发言，先显示 `\FF[right_id]` 并用 `\AA[FF]`；左侧到发言时再显示。旁白后恢复角色对白时，重新指定该角色的 AA 聚焦。

有配音时，按[角色配音手记](how-to-add-voice-acting-to-characters.md)在对应对白前放 Play VSC；立绘控制符仍写在该句对白中。

## 检查效果

确认单人左站、第二人右站并反转；两人按实际发言顺序出现。轮流说话时只有说话者高亮，其他人变暗；旁白时全部变暗，旁白后能恢复说话者聚焦。检查立绘不遮挡必要文字、没有残留在下一段无关场景。
