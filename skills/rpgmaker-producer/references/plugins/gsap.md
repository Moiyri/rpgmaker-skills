# GSAP：复杂元素动画库

GreenSock Animation Platform（GSAP）是 JavaScript 动画库，不是 RM 插件。用户指定：需要复杂元素动画、复杂 UI 动画时可以使用此库，由游戏插件调用并整合。

[官网](https://gsap.com)来自本地库头部。常用分发文件为 `gsap.min.js`，按项目目录约定放在 `js/plugins/tools/gsap.min.js`。shadow 已有并启用 `tools/gsap.min`，文件头部版本为 3.14.2；版本是本地快照，不代表最新。

## 工程接入

可以通过 RM 插件清单加载库文件，库应在依赖它的游戏插件之前加载；实际调用前检查运行时库是否可用。注册、启用和排序仍通过 rpgmaker-plugins 正式脚本进行。库不是带 RM 参数与插件命令的功能插件，不要求它具有 RM 编辑器声明。

复杂 UI 动画可优先评估 GSAP；简单效果按实际需求实现，不为简单动画强制引入库。所需 API 和动画目标结合当前库版本及工程对象查阅确认。场景结束或对象销毁时处理仍在运行的动画，避免继续操作已失效的元素。

本次仅核对文件头部与插件清单，未测试 UI 动画，也未自动安装其他 GSAP 扩展。
