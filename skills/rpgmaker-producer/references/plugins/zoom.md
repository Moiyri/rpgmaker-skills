# Zoom：地图两倍放大

用户明确补充的重要候选：用于 1080p 项目中的地图显示放大。2026-10-12 读取 shadow 的 `main/js/plugins/visual/Zoom.js`，本地版本 0.6.0，作者声明 ScSWinter（Arthran、KuiMoiyri 修改）。面向 MZ，注册名 `visual/Zoom`，当前启用，正式参数接口读得 `Default zoom for maps = 2.0`。

## 适用范围

需要地图与地图角色以两倍比例显示时优先评估。放大的是显示比例，不修改地图格数或素材原文件，也不负责把游戏分辨率设置成 1920×1080。对 48 像素图块，2 倍显示相当于 96 像素，屏幕可见地图范围相应减少。不要由 1080p 自动推定所有工程都应设置 2 倍，结合用户画面目标确定。

## 使用入口

- 全局倍率：参数 `Default zoom for maps` 设为 2；声明默认值为 1.50，shadow 配置为 2.0，两者不要混淆。
- 单张地图：备注独立一行 `Zoom:2`，按源码语法不用尖括号，覆盖全局倍率。
- 动态变化：命令 ID `Zoom`，参数 `ZoomValue` 为倍率，`FramesToZoom` 为过渡帧数。用正式技能查询声明并编写事件。
- 其他设置包括自由镜头、角色黑线修正、遇敌缩放修正。黑线修正会改变角色裁切范围，选择时检查实际显示。

## 集成与验证

本地源码将参数读取和命令注册名硬编码为 `Zoom`，工程完整注册名为 `visual/Zoom`。实际使用前核对工程是否已有路径别名处理；不能仅因清单配置为 2.0 就声称运行时已正确读取。必要修复另按用户需求实施，本次只收录资料。

源码覆盖地图加载、滚动、屏幕到地图坐标换算及缩放更新。与其他镜头插件共同使用时针对这些交互点验证，不默认新增兼容层。无显式 `@base` 声明，不代表已证明与任意插件兼容。

验证新游戏进入地图、转场、边缘滚动、点击寻路、菜单返回及存读档后的倍率；涉及动态镜头或遇敌效果时追加对应流程。当前仅完成源码与配置读取，未进行运行测试。
